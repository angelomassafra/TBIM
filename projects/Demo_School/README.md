# Demo School - TBIM tutorial project

The two-block school of the [user manual tutorial](../../docs/USER_MANUAL.md#4-tutorial-the-demo-school-step-by-step):
block A has two storeys with three rooms and a corridor per floor, block B is a single-storey gym (9 cells).

| | |
|---|---|
| `3d/`, `json/` | Inputs and TBIM data of every step of the workflow |
| `Demo_School.rvt` | Revit 2026 model at the end of step 6 |
| `export/` | IFC4 with the TBIM property sets; InstanceBIM as topologicpy JSON, BREP, OBJ and dual graph |
